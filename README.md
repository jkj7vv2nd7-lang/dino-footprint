# おおきな あしあと ― みなみそうまの きょうりゅう

南相馬で見つかった恐竜の足跡を題材にした、小学2年生くらいのお子さんと読んで遊べるアプリです。

- 読み物：南相馬の恐竜足跡のお話（挿絵つき）
- 遊び8つ：足跡クイズ、大きさ比べ、恐竜の名前あて など
- 恐竜とのおしゃべり機能

## 使い方
1. `index.html` をブラウザ（Chrome / Edge / Safari）で開きます。
2. iPhoneでは「ホーム画面に追加」で、恐竜の足跡アイコンから起動できます（`footprint.webp` と同じ場所にファイルを置いてください）。

## ファイル
- `index.html` … アプリ本体（単体HTML）
- `footprint.webp` … 挿絵（大きな恐竜の足跡と子どもの靴のあと）
- `icon.png`（1024×1024）／`icon-180.png`（apple-touch-icon用）… 挿絵から作成したアイコン
